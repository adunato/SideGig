# itch.io Game Assets

- **Channel class:** Game-Development Asset and Tool Marketplaces
- **Channel URL:** https://itch.io/game-assets
- **Assessment status:** Discovered

## Description

itch.io’s marketplace section for game-development assets such as sprites, audio, UI packs, fonts, 3D models and tools. Creators can self-publish paid asset packs to the same indie-development community that uses itch.io for games.
