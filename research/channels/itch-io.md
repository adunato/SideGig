# itch.io

- **Channel class:** Game Distribution Stores
- **Channel URL:** https://itch.io/developers
- **Assessment status:** Discovered

## Description

An open marketplace for independent games and game-related digital products. Developers can self-publish rapidly, set fixed or pay-what-you-want pricing, participate in bundles and sales, and reach an audience particularly oriented toward indie and experimental games.
