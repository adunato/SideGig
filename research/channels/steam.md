# Steam

- **Channel class:** Game Distribution Stores
- **Channel URL:** https://partner.steamgames.com/steamdirect

## Description

Valve’s dominant PC game distribution marketplace. Independent developers can publish commercial games through Steam Direct and access a large global player base, store discovery, payments, updates, reviews, community features and downloadable-content distribution.
