# Epic Games Store

- **Channel class:** Game Distribution Stores
- **Channel URL:** https://store.epicgames.com/en-US/distribution
- **Assessment status:** Discovered

## Description

Epic’s PC game storefront and distribution channel. Approved developers can sell games to Epic’s consumer audience using Epic’s commerce, delivery and update infrastructure, with the store positioned as a major alternative to Steam.
