# AWS Data Exchange

- **Channel class:** Data Marketplaces
- **Channel URL:** https://aws.amazon.com/data-exchange/
- **Assessment status:** Discovered

## Description

AWS’s service for publishing, discovering and subscribing to third-party data products. Eligible providers can package datasets and recurring data products that are sold through AWS Marketplace and consumed directly inside AWS workflows.
