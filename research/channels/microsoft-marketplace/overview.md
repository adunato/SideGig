# Microsoft Marketplace

- **Channel class:** Cloud Software Marketplaces
- **Channel URL:** https://marketplace.microsoft.com/
- **Assessment status:** Discovered

## Description

Microsoft’s commercial marketplace for software and services sold into Microsoft’s cloud and enterprise ecosystem. Vendors can distribute SaaS and cloud offers to Azure and Microsoft business customers using Microsoft marketplace procurement and billing.
