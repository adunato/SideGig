# AutomationMart

- **Channel class:** Automation and Integration Marketplaces
- **Channel URL:** https://automationmart.io/
- **Assessment status:** Discovered

## Description

An open marketplace for Make, n8n and Zapier workflow files. Sellers can list reusable automation packages for direct purchase and instant download, with the platform handling checkout and seller payouts.
