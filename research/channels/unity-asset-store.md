# Unity Asset Store

- **Channel class:** Game-Development Asset and Tool Marketplaces
- **Channel URL:** https://assetstore.unity.com/
- **Assessment status:** Discovered

## Description

Unity’s first-party marketplace for game-development assets, including editor tools, code systems, AI integrations, shaders, templates, 2D/3D assets and audio. Publishers can sell reusable products directly to Unity developers.
