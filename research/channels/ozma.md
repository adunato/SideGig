# Ozma

- **Channel class:** API and Microservice Marketplaces
- **Channel URL:** https://ozma.app/
- **Assessment status:** Discovered

## Description

A developer-oriented API marketplace designed around publishing and monetising HTTP APIs. It combines marketplace discovery, metering and billing so independent developers can sell specialised API capabilities without building a full commerce stack.
