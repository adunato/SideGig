# Zoom App Marketplace

- **Channel class:** Platform App, Plugin and Extension Marketplaces
- **Channel URL:** https://marketplace.zoom.us/
- **Assessment status:** Discovered

## Description

Zoom’s marketplace for applications and integrations that operate with Zoom products. Developers can distribute tools for meetings, communications, productivity and business workflows to organisations already using the Zoom ecosystem.
