# RapidAPI

- **Channel class:** API and Microservice Marketplaces
- **Channel URL:** https://rapidapi.com/hub

## Description

A large public API marketplace where providers can publish hosted APIs and buyers can discover, test and subscribe to them. The platform provides API discovery, plan configuration, usage metering and marketplace billing for narrowly scoped programmatic services.
