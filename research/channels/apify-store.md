# Apify Store

- **Channel class:** API and Microservice Marketplaces
- **Channel URL:** https://apify.com/store
- **Assessment status:** Discovered

## Description

Apify’s marketplace for cloud-hosted Actors: reusable programs for web scraping, automation, data extraction and AI-agent tooling. Developers can publish Actors that run on Apify infrastructure and monetise them through usage-based or rental pricing.
