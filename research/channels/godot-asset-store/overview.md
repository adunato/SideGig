# Godot Asset Store

- **Channel class:** Game-Development Asset and Tool Marketplaces
- **Channel URL:** https://store.godotengine.org/
- **Assessment status:** Discovered

## Description

Godot’s new official asset store for reusable game-development assets and tools, introduced in 2026. It provides a dedicated distribution surface for the growing Godot ecosystem and is intended to succeed the older Asset Library model.
