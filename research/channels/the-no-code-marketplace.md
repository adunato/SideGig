- **Channel class:** Automation and Integration Marketplaces

## Description

A marketplace focused on premium Zapier, Make and n8n workflows plus ready-to-deploy AI agents. Creators can upload workflow files, set prices and sell them directly to users seeking reusable no-code automation solutions.
