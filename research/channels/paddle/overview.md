# Paddle

- **Channel class:** Direct Software and Digital-Product Storefronts
- **Channel URL:** https://www.paddle.com/
- **Assessment status:** Discovered

## Description

A merchant-of-record billing platform for SaaS, applications and digital products. Paddle handles payments, subscriptions, global tax, compliance, fraud and customer billing so software vendors can sell directly without building the full commerce back end.
