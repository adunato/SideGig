# Setapp

- **Channel class:** Standalone Application Stores
- **Channel URL:** https://setapp.com/developers
- **Assessment status:** Discovered

## Description

A curated subscription-based application catalogue focused primarily on macOS. Participating developers place their applications inside a single consumer subscription and receive revenue through Setapp’s developer payout model rather than selling individual licences directly.
