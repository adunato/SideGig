# GOG

- **Channel class:** Game Distribution Stores
- **Channel URL:** https://www.gog.com/

## Description

A curated PC game storefront operated by CD Projekt, known for DRM-free distribution. Developers and publishers can submit commercial games for consideration and reach a PC audience that values curated releases and ownership-friendly distribution.
