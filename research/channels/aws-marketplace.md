# AWS Marketplace

- **Channel class:** Cloud Software Marketplaces
- **Channel URL:** https://aws.amazon.com/marketplace
- **Assessment status:** Discovered

## Description

Amazon Web Services’ marketplace for third-party SaaS, machine images, containers, data products and other cloud software. Sellers can reach AWS customers and use AWS procurement, metering, billing and private-offer mechanisms.
