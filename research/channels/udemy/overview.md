# Udemy

- **Channel class:** Knowledge and Technical-Content Marketplaces
- **Channel URL:** https://www.udemy.com/
- **Assessment status:** Discovered

## Description

A global marketplace for self-paced online courses. Instructors can publish finished technical or professional courses and sell them to Udemy’s existing learner base, with the platform handling course delivery, checkout and marketplace discovery.
