# Chrome Web Store

- **Channel class:** Platform App, Plugin and Extension Marketplaces
- **Channel URL:** https://chromewebstore.google.com/
- **Assessment status:** Discovered

## Description

Google’s distribution marketplace for Chrome browser extensions and themes. Developers can reach a very large browser user base with focused extensions, while monetisation can be attached to paid services, subscriptions or external commerce around the extension.
