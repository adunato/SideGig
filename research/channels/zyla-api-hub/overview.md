# Zyla API Hub

- **Channel class:** API and Microservice Marketplaces
- **Channel URL:** https://zylalabs.com/api-marketplace
- **Assessment status:** Assessed
- **Assessment date:** 2026-08-31

## Description

Zyla API Hub is a commercial API marketplace where independent providers can publish hosted APIs and developers can discover, test and subscribe to them through a common account, API key and billing layer. Zyla markets the hub as a large developer ecosystem and has recently added MCP compatibility for agent-driven API consumption.

## Channel Assessment

Assessment framework: [../channel-assessment-framework.md](../channel-assessment-framework.md)

A higher score always means a more attractive channel for this project.

| Metric | Score (1–5) | Confidence | Evidence and rationale |
|---|---:|---|---|
| Paying demand | **4** | Medium | Zyla currently claims **5M+ developers, 10,000+ APIs and 3B+ API calls per month**. Its terms and provider documentation confirm active paid subscriptions, revenue sharing and provider payouts, while recent 2026 customer reviews confirm current API usage. These are strong indicators of a live market, but Zyla does not publish GMV, paid-subscriber counts or the share of calls generated by paid plans, so the score relies partly on usage as a demand proxy. |
| Opportunity density | **3** | Low | The headline ratio of billions of monthly calls against roughly 10,000 APIs suggests substantial aggregate usage relative to catalogue size, but actual call and revenue distribution across listings is not public. Zyla's catalogue contains thousands of APIs in popular categories and many offers include free trials, so demand may be concentrated. The evidence supports a viable marketplace but not a clearly favourable demand-to-supply ratio for a new seller. |
| New-entrant attainability | **3** | Low | Publishing is free, unlimited and available to independent providers. Zyla handles onboarding, discovery, first-level support and marketplace billing, while APIs are reviewed by its quality-control team. This makes entry operationally accessible. However, no public cohort data or credible recent seller case studies were found showing what proportion of newly listed APIs acquire paying subscribers, so attainability is inferred rather than directly observed. |
| Revenue potential | **4** | Medium | Providers normally receive **80% of subscription revenue**, making the project's £2,000–£5,000 annual target commercially modest if an API can attract a small recurring subscriber base. Zyla's large claimed usage base supports the possibility of meaningful revenue. The main qualification is that revenue share falls sharply if monthly uptime drops below 99.9%, and current seller-income distributions are private. |
| Competitive pressure | **2** | Medium | More than 10,000 APIs are listed, with hundreds or thousands of offerings in several broad categories. Free trials are widespread and API functionality is often straightforward to replicate, creating strong commoditisation and search competition. Narrow specialist APIs can still differentiate, but a generic utility API is likely to face substantial pressure. |
| Production leverage | **5** | High | The product form is highly aligned with software-development and AI-assisted production leverage. Narrow APIs, data transformations, scrapers and AI-backed services can be produced, tested and iterated rapidly, while Zyla supplies discovery, subscription billing, API-key access and first-level support. |
| Operating burden | **2** | High | The provider remains responsible for keeping the underlying API operational. Zyla's payout terms strongly penalise downtime: the normal 80% provider share applies only at 99.90–100% uptime, falls progressively below that, and reaches zero below 95%. Structural API changes are reviewed and must avoid breaking subscribers. Zyla handles first-level customer support, which helps, but a revenue-producing API remains a continuously operated service that cannot simply be paused for weeks. |

### Supporting assessments

- **Trend:** Growing
- **Evidence confidence:** Medium

Zyla appears operationally active and is continuing to invest in the marketplace, including MCP/agent compatibility. Current first-party pages claim 3B+ monthly calls and recent independent customer reviews show active usage and support interactions in 2026. The growth judgement is nevertheless based largely on current platform claims rather than independently audited historical series.
