# Slack Marketplace

- **Channel class:** Platform App, Plugin and Extension Marketplaces
- **Channel URL:** https://slack.com/apps
- **Assessment status:** Discovered

## Description

Slack’s directory and distribution channel for third-party applications that add workflows, integrations and functionality to Slack. Developers gain access to teams already using Slack, with monetisation typically attached to the developer’s own paid app or service.
